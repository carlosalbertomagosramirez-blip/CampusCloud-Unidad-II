# Reporte técnico - versión previa a la ejecución

El archivo PDF se genera mediante `tools/generar_reporte.py` y tiene 9 páginas planeadas. Se incluye como **borrador técnico**, no como evidencia de éxito: todavía faltan las capturas y resultados reales de Docker/MongoDB/Neo4j/Cassandra que exige el maestro.

Después de ejecutar las prácticas, completa `docs/pruebas.md`, comparte las capturas y actualiza el reporte para sustituir los recuadros de «evidencia pendiente» por pruebas verificadas.

El PDF de entrega se llama `Magos_Carlos_ReportePracticas_NoSQL.pdf` y se presenta separado del ZIP.
